# Secant Geometry

**Secant Geometry** is an open research and engineering organization building multimodal sensing, spatial computing, GPU tooling, and applied machine learning systems.

We make tools and platforms for turning messy real-world signals into shared, usable representation spaces — with a focus on rigor, visualization, reproducibility, and climate-relevant applications. 🧪

## What We Work On

- **Multimodal sensing**
    - Electrical impedance
    - Acoustics
    - Vision and spatial capture
- **GPU-native tooling**
    - Shader authoring and visualization
    - WebGPU and desktop rendering workflows
    - Real-time feedback and simulation loops
- **Spatial representation**
    - Locality-preserving encodings
    - Structured sensor layouts
    - Shared feature spaces for heterogeneous data
- **Applied machine learning**
    - Sensor fusion
    - Monitoring and anomaly detection
    - Reproducible evaluation pipelines

## Current Focus

Our current work centers on a multimodal sensing platform that combines electrical, acoustic, and visual data into shared representation spaces.

This platform includes:

- A browser-based WebGPU shader editor
- Cross-platform Qt rendering tools
- Spatial encoding and ML-oriented data pipelines
- Documentation and experiments for multimodal sensing workflows

It was initially shaped around aquaculture and aquatic monitoring, but the architecture is intended to generalize to other sensing-heavy domains. 🌊

## Why This Exists

Most sensing systems are built in silos: one sensor, one dashboard, one narrow interpretation of reality. We think the more interesting path is to combine modalities, preserve structure, and build tools that let people actually see and test what the system is doing.

That means:

- Open code where possible
- Honest documentation of failures, not just wins
- Clear separation between validated results and speculation
- Tools that are useful for both research and real engineering work

Basically: less hand-waving, more working artifacts.
