# Secant Geometry

Secant Geometry is an organization founded by **Joel Van Eenwyk** and **Chris Birke**, focused on
the intersection of mathematics, geometry, and software engineering.

## About

The name *Secant Geometry* reflects the founders' shared passion for mathematical concepts and
their practical applications in software. A secant is a line that intersects a curve at two or
more points — a fitting metaphor for bridging theoretical geometry with real-world engineering.

## Founders

- **Joel Van Eenwyk** — Software engineer with expertise in low-level systems programming,
  graphics, emulation, and DevOps tooling.

- **Chris Birke** — Developer and speaker known for work on mathematical rendering techniques,
  including implicit function raytracing, and contributions to game programming mathematics.

## Focus Areas

- Mathematical and geometric algorithms
- Graphics and rendering
- Software tooling and automation
- Open source collaboration
